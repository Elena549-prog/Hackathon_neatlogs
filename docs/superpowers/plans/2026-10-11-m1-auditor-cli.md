# M1 Strategy Auditor CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `python -m src.auditor "<idea>"` runs one audit end to end without follow-ups: Planner → frozen plan v0 → data → backtest, baseline, statistics, coded checks → one Naysayer critique → verdict → `events.jsonl`, `state.json`, template report, registry line.

**Architecture:** Pure code modules with injectable I/O: `plan.py` (schema, validation, freeze), `data.py` (fetchers with injectable `download`/`query`, vectorised features), `backtest.py` (trade rules), `checks.py` (statistics), `verdict.py` (rules), `report.py` (template, registry), `eventlog.py` (events.jsonl), `agents.py` (prompts and LLM calls), `fake_llm.py` (keyword planner for tests and dev runs), `run.py` (orchestrator with state and resume), `__main__.py` (CLI, balance check, faults). The existing `src/llm.py` wrapper and `src/tracing.py` Tracer are reused; the Tracer gains an `on_span` callback that becomes `llm_call` and `recovered` events.

**Tech Stack:** Python 3.13 venv (`.venv/bin/python`), pandas, numpy, yfinance, openai (DeepSeek), neatlogs via `src/tracing.py`, pytest. Branch `m1-auditor` from `m3-ui`.

**Spec:** `docs/AUDITOR_SPEC.md` sections 2 (families, trade rules, universe groups), 3 (splits, windows, leakage), 4 (loop, budget), 5 (plan schema), 6 (data, features, faults), 7 (statistics, checks, verdict), 8 (state, budget, balance), 9 (report, CLI), 10 (tracing), 11 (reuse and required changes), 12 (tests), 16 (event contract: `src/auditor/events.py` on this branch).

## Global Constraints

- Paper trading and historical replay only. Never read or construct the test split (setups on or after 2026-07-01). Never import `TICKERS`, `split_for`, `load_market`, `load_prices` from `src/data.py`, `src/labels.py`, `src/tools.py`.
- Splits: train setups 2015-01-01 to 2025-12-31 (straddles from 2020-01-01), dropped if the exit date is on or after 2026-01-01; validation setups 2026-01-01 to 2026-06-30, dropped (and counted) if the exit falls past the fetched data.
- Data windows: prices 2014-01-01 to 2026-07-30 exclusive (universe plus SPY and ^VIX, `auto_adjust=False`); implied vol 2019-06-01 to 2026-06-30 in 14-day windows; earnings `get_earnings_dates(limit=60)`. Caches under `data/cache/` (gitignored).
- Trade rules, section 2: `stock_long` entry at Adj Close, stop and target absolute prices, Open/High/Low scaled by Adj Close / Close, gap fills at the Open, stop first on a same-day double hit, horizon exit at that day's Adj Close, one open trade per ticker. Straddles: payoff `|Close(t+10)/Close(t) − 1|` on split-adjusted Close; cost = 0.7979 × IV × √(10/252); buyer pays × 1.05, and × 1.20 more when an earnings date falls in the 10-day window; seller receives × 0.95; buyer return = payoff/cost − 1; seller return = (premium − payoff)/premium; trade skipped when the latest IV row is more than 5 calendar days old.
- Plan rules, section 5: family in {stock_long, straddle_buy, straddle_sell}; `universe_group` one of the 8 names; 0 to 4 conditions on section 6 features with operators `>`, `<`, `>=`, `<=` and numeric values; implied-vol features rejected for `stock_long`; `exit` required for `stock_long` with target 1–20%, stop 1–20%, horizon 1–20 days, ignored for straddles; `not_tested` list of strings; `core_trigger_tested` boolean; `refuse.is_refused` ends as `cannot_audit` "refused". Plan v0 = canonical JSON (sorted keys), hash = SHA-256 of that text. One Planner fix after an invalid plan; a second invalid plan ends as `cannot_audit` "no valid plan".
- Statistics, section 7: trades `n`, distinct 10-trading-day blocks, win rate, mean, median, worst trade, worst 10-trading-day window of summed returns; `bootstrap_mean`: block bootstrap over 10-trading-day blocks of entry dates, 2000 resamples, 2.5th and 97.5th percentiles; paired lower bound = 2.5th percentile of (v0 mean − baseline mean) on the same resampled blocks; stricter cost (straddles): buyer cost +10%, seller premium −10%; tail risk on train plus validation; `straddle_sell` downgrade if worst trade < −5 average premiums or worst-window loss > total validation gain.
- Verdict order, section 7: `cannot_audit` (refused, invalid twice, core trigger untestable) → `inconclusive` if validation `n` < 30 or blocks < 6 → `kill` if validation mean ≤ 0 → `promising` only if lower bound > 0, paired lower bound > 0, train mean > train baseline mean, straddles pass stricter cost, passes tail risk, no downgrade → else `inconclusive`.
- Budget, section 8: at most 8 `llm()` calls per audit; the 8th is reserved for the Reporter; the other roles may use at most 7; the count is persisted in `state.json` and checked before every call.
- Report, section 9: order 1–10 as listed; subtitles "Passed a 6-month historical screen. Not a forecast. Not financial advice." (promising) and "inconclusive: a strategy with no real edge lands here about half the time"; banned phrases "will profit", "guaranteed", "risk-free", "we recommend", "you should buy", "you should sell", "sure thing"; shared-window line "About 5% of plans with no real edge pass this test by chance; testing many variants of one idea raises that."; footer: not financial advice, survivorship bias, one validation window, costs approximated. No position sizing anywhere.
- Events: every emitted event passes `src.auditor.events.validate_event`; `seq` continues across `--resume`.
- CLI (section 9): `python -m src.auditor "<idea>"`, `--id <audit_id>`, `--resume <audit_id>`, `--fault dolthub_timeout|llm_empty`, plus `--provider deepseek|claude|fake` and `--no-balance-check`. DeepSeek runs refuse to start below $2.
- Never commit secrets; `.env` stays out; never print keys.

## Review Focus

1. A ticker whose price history is shorter than 200 rows (or missing from Yahoo) must be skipped with a coverage note, not crash feature building. Test in Task 3.
2. A validation trade whose horizon runs past the last fetched price must be dropped and counted, never read beyond the data. Test in Task 4.
3. The Planner returning conditions in the list form with a string value, or a duplicate feature, must produce an invalid-plan message, not a TypeError. Test in Task 2.
4. An audit interrupted after the backtest and resumed must not call the Planner again and must continue `seq`. Test in Task 8.
5. `bootstrap_mean` with fewer than 2 blocks must return a finite interval (the mean itself), not raise. Test in Task 5.
